# ADR-009: Yerel Komuta Paneli ve terminal komutu (Faz 8, M1 #1 çekirdeği)
Durum: kabul (2026-10-21). Kapsam seçimi: yetenek matrisinde Faz 8 = M1/M12/M13/M2 arayüz-operasyon grubu. Küçük dilim: **#1 Komuta Merkezi**'nin salt-localhost, tek kullanıcılı, bağımlılıksız çekirdeği (Docker yok, dış paket yok, model çağrısı yok). Ertelenen: #16 görsel iş akışı editörü, #20 mobil, #28/#8 gözlemlenebilirlik, #91–93 uyarlanabilir arayüz.
- **Aynı sunucudan statik servis:** üç sabit dosya (`/`, `/ui/app.js`, `/ui/style.css`), açılışta belleğe okunur; istekten yol üretilmez (gezinti yok). Dosyalar veri/sır taşımaz; veri `/api/*` ile ve belirteçle gelir.
- **Belirteç:** yalnızca `Authorization: Bearer` başlığında (çerez yok → CSRF'e kapalı; `requireJson` basit form POST'unu da keser). CLI `ui` komutu paneli `http://127.0.0.1:PORT/#token=…` ile açar; URL parçası sunucuya gitmez, panel onu sekmenin `sessionStorage`'ına alır ve adres çubuğundan siler (`hashchange` ile açık sekme de yakalar). Elle girişte `type=password` alan.
- **Sıkı CSP:** `default-src 'none'; script-src 'self'; style-src 'self'; connect-src 'self'; img-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'` + `nosniff`, `X-Frame-Options: DENY`, `no-referrer`, `no-store`, COOP/CORP. Satır içi betik/stil/olay yok (kaynak testi sabitler); gerçek tarayıcıda `eval` bile engelli.
- **XSS:** sunucu verisi yalnızca `textContent` ile yazılır; tehlikeli HTML API'leri yok (test sabitler); gerçek Edge testinde `<img onerror>` başlığı düz metin kalır.
- **Eylem yüzeyi bilerek dar:** yalnızca görev onayı/reddi; diğer bölümler salt okunur. Her eylem, görev başlığını gösteren bir onay penceresinden geçer ve imleç/odak onay kuyruğundayken otomatik yenileme listeyi değiştirmez (kayan satıra yanlış tıklama / arayüz kaydırma).
- **Terminal komutu** (`npm run agentmom -- durum|gorevler|onay|borc|kararlar|ui`): yalnızca loopback `baseUrl` (belirteç başka adrese gitmez), `redirect:error`, belirteç hiçbir çıktıya yazılmaz, sunucudan gelen metinden terminal kaçış dizileri temizlenir.
- Bilinen sınırlar: belirteç sekme boyunca bellekte/sessionStorage'dadır (aynı sekmede çalışan kötü amaçlı betik olmadığı sürece güvenli; XSS yolu kapatıldı); `ui` komutu belirteci kısa süre `cmd start` süreç argümanında taşır (yerel kullanıcı bağlamı); panel tek kullanıcılıdır, çok kullanıcı/rol (#31) yok.
