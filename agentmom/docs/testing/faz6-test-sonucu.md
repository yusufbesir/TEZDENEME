# Faz 6 test sonucu (2026-10-21): REA küçük dilim
Tam paket: **320/320 geçti**, tsc temiz (`faz6-test-ciktisi.txt`). Karar: ADR-007.

## Kapsam ve kanıt
1. **Kaynak kaydı** (`rea_sources`): tür (resmi belge / sürüm notu / kasa notu / depo belgesi), güvenilirlik (tür başına üst sınır), tazelik (tür başına gün), lisans, güvenlik notu; yerel kaynak gerçek yola çevrilip politika kapısından okunur, SHA-256 sabitlenir; `anahtarlar`/`Arşiv` ve symlink/junction ile kaçış reddedilir. Belge kaynakları yalnız https + "ne zaman okundu" olarak kaydedilir, çekilmez.
2. **Bulgu → öneri:** bulgular dosya:satır kanıtlıdır (kaynak değişmişse reddedilir). Öneri kontrolleri: kanıt, tazelik, güvenilirlik, lisans, güvenlik (kod bloğu/talimat benzeri içerik), uyumluluk (yol), çakışma (mevcut özelliklerle benzerlik), politika sınırı; puanlar (değer, maliyet, risk, karmaşıklık, bakım) ve öncelik. Öneri SQLite'a ve bellek modülüne bağlıdır (riskli/yürütülebilir görünenler belleğe yazılmaz).
3. **Onay iş akışı:** öneri → izole deney (gerçek git worktree, `file.read`+`file.write` politikası + kullanıcı) → taban çizgisi → sonuç (≥3 koşu, gürültü >%10 = karar yok, ≥%5 iyileşme) → onaya sun → kullanıcı onayı → izleme (gerileme yalnız bildirilir) → geri alma. Hepsi yalnız kullanıcı.
4. **REA politikayı değiştiremez (kodda + SQL'de + testte):** izin listesi yaklaşımı (yalnız `docs` alanı ve `docs/` yolları serbest; geri kalan her şey `user_decision_required`), ayrıca metin ağı (Unicode NFKC, sıfır genişlik, homoglif, boşluklu harf, Türkçe/İngilizce eş anlamlılar); SQL tetikleyicileri iş akışına girişi, doğrudan INSERT ile durum atlamayı, içerik ve politika bayrağı değişimini engeller. 17 bypass denemesi testtedir.
5. **Ucuz yol:** keşif deterministik satır tarama; model çağrısı yok (`ModelBudget` varsayılan 0).
6. **Gerçek küçük uçtan uca deneme** (`scripts/e2e-rea-demo.sh`, çıktı `faz6-rea-demo-ciktisi.txt`): sunucu + kullanıcı yapılandırması + yalnız yerel notlar (gemini.md, codex-okuma-kapsami.md, codex-antigravity-tarama.md, durum.md), internet ve model yok. Keşif: 6+3+3 bulgu (örnek: `gemini.md:9` "execute … unavailable"). Öneri 1 (belge-yalnız) `proposed`, öncelik 4, tüm kontroller ok. Öneri 2 (yükseltilmiş Codex sandbox) `user_decision_required`; deney isteği **HTTP 403** ("changes policy and never enters the adoption workflow"). Not: Yusuf sonradan Gemini'yi beklemeye aldı; "Antigravity araştırması" önerisi yalnız demo kaydıdır, uygulanmadı.

## Bağımsız güvenlik denetimi (guvenlik-denetcisi, Sonnet) — KALDI (şartlı) → düzeltildi
Orta ×4, düşük ×3. Düzeltilen: (1) politika dedektörü atlatmaları (sıfır genişlik, homoglif, boşluk, eş anlamlı, yol hileleri `docs/../`, `policy `, `:akış`) → izin listesi + sıkı normalizasyon; (2) doğrudan INSERT ile durum atlama → `rea_recs_birth_state` tetikleyicisi; (3) `Infinity`/NaN ile sahte "improved" → geçersiz ölçüm = karar yok, koşular ±1e12 ile sınırlı; (4) talimat benzeri metin belleğe yazılıyordu → artık yazılmaz, başlık da temizlenir, regex güçlendirildi (wget/irm/iex, bölünmüş sözcükler); (5) boyut TOCTOU → okuma sonrası kontrol; (6) ret/geri alma notları maskelenir ve 1000 karakterle sınırlı; ayrıca symlink ile okuma kapısı aşımı (otomatik tarayıcı bulgusu) → `realpath` ile gerçek yol. Kabul edilen: (7) iki eşzamanlı deney isteğinde yetim worktree olasılığı çok düşük (git ikinciyi reddeder). Sınır: güvenilirlik/lisans/tazelik alanlarını kaydı giren kullanıcı beyan eder; REA doğrulayamaz.
