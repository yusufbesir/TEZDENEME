# TAARKOD 1.7.0 (teslim: D:\Programlar\TAARKOD)

- Kurallar barkod türüne göre: her tür kendi değerlerini ayrı tutar (EAN-13, EAN-8, UPC-A, ITF-14 GS1 ön ayarı; Code 128 eski kurallarıyla aynı). Türe özel kurallar yalnız o türde görünür. Alanlar türe uygun ön ayarla gelir, kurala uygun düzenlenebilir. Mavi (i) balonlar sürüyor.
