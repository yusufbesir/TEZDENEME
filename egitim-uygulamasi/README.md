# Adım Adım: öğrenme uygulaması

Derleme gerektirmeyen, çevrimdışı çalışan düz HTML/CSS/JS uygulaması. `index.html` dosyasını tarayıcıda açın.

- Kurslar: İngilizce A1 (`ingilizce-1`), HTML, CSS, JavaScript (`icerik/`).
- Özellikler: kısa dersler, 5 alıştırma türü, XP, seviye, seri, günlük hedef, aralıklı tekrar (5 kutu), açık/koyu tema.
- Veri yalnızca tarayıcının localStorage alanında tutulur; ağ isteği yoktur.
- Yeni kurs eklemek için `icerik/` altına şemaya uygun dosya koyup `index.html`'e script satırını ekleyin (bkz. `SOZLESME.md`).
- Test: `node --test "egitim-uygulamasi/test/*.test.js"`
